# Questionário: Segunda Guerra Mundial 🌍

Este é um projeto simples desenvolvido em **Python** que funciona como um quiz interativo via terminal. O tema central aborda os antecedentes, o desenvolvimento militar e os desdobramentos da Segunda Guerra Mundial (1939-1945).

O objetivo da aplicação é testar os conhecimentos históricos do usuário e treinar a interpretação de texto, utilizando o formato de questões de múltipla escolha (estilo ENEM).

## 🚀 Funcionalidades

* **Interatividade no Terminal:** O usuário responde às perguntas diretamente no console.
* **Sistema de Pontuação:** O script rastreia os acertos em tempo real e exibe o *score* atualizado após cada resposta.
* **Feedback Imediato:** Informa na hora se o usuário acertou ou errou, indicando a alternativa correta em caso de erro.
* **Cálculo de Desempenho:** Ao final das 5 questões, o sistema calcula e exibe a taxa de aproveitamento em porcentagem (%).

## 🛠️ Tecnologias Utilizadas

* **Python 3.x:** Linguagem de programação utilizada para construir a lógica do questionário, manipular entradas de texto (`input`) e estruturas condicionais (`if/else`).

## ⚙️ Como Executar o Projeto

1. Certifique-se de ter o **Python** instalado em sua máquina. Você pode verificar digitando no terminal:
   ```bash
   python --version
   ```
2. Salve o código em um arquivo com a extensão `.py`, por exemplo: `quiz_historia.py`.
3. Abra o terminal (ou prompt de comando) e navegue até a pasta onde o arquivo foi salvo.
4. Execute o script com o seguinte comando:
   ```bash
   python quiz_historia.py
   ```
5. Siga as instruções na tela, digitando "sim" para iniciar e escolhendo as alternativas (A, B, C, D ou E) para cada questão.

## 📝 Estrutura das Questões

O quiz é composto por 5 questões abordando os seguintes temas:
1. Consequências do Tratado de Versalhes.
2. O Pacto de Não Agressão (Molotov-Ribbentrop).
3. A entrada dos Estados Unidos no conflito (Pearl Harbor).
4. O ponto de virada militar na Batalha de Stalingrado.
5. O "Dia D" e a Operação Overlord na Normandia.
